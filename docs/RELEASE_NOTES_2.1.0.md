# HybCapSeq-Quant 2.1.0

配套数据库修订为v3.3.1，现有目录名称及文件名可以继续使用。

- `upgrade-db`校验并备份现有文件，将Rochester乙流8条参考的组装长度统一为13,859 nt，同时更新质量注释和校验清单。FASTA和MMI保持原样。
- 兼容旧EsViritu结果中已确认的历史组装长度；原始字段保留，计算使用修订分母，并输出修正明细。
- 探索性模式默认输出可计算的区间外估计，同时保留范围状态；正式模式仍默认禁止外推。最低ERCC浓度不自动定义为LoD/LoQ。
- 核对完整参考组的长度、成员数、质量状态及质量算术，防止引用数据不一致被当作低浓度问题。

安装与数据库更新步骤见[升级说明](https://github.com/Lt1020/HybCapSeq-Quant/blob/main/docs/UPGRADE_2.1.0.md)。完整数据库更新逻辑随Python软件分发；发行附件另外提供修订注释与更新说明。
